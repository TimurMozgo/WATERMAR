# Aqua Service — GitHub Pages + Google Apps Script

## Публикация
1. Загрузите этот проект в репозиторий GitHub (ветка main или master).
2. Settings → Pages → Source → GitHub Actions.
3. Во вкладке Actions дождитесь Publish GitHub Pages. При необходимости Run workflow.
4. Полученную HTTPS-ссылку укажите для Mini App в BotFather.

Публикуется только public/. Пути работают и в подпапке репозитория.
Адрес уже опубликованного API находится в public/config.js. Никаких токенов туда добавлять не надо.

## Проверка
Оба администратора (394814448, 6088315974) должны открыть бота и нажать Start.
Откройте приложение через Telegram: Управление → Добавление товаров. Добавьте товар с фотографией, затем оформите заказ.
Проверьте лист Заказы TMA, сообщения бота и решение в Управление → Заказы.
Сообщения обрабатываются раз в минуту. APP_URL в свойствах Apps Script можно задать после публикации сайта для кнопок в сообщениях.
Заказ из обычного браузера без Telegram не принимается.

## Разработка
npm run preview:pages — статический сайт с настоящим Apps Script, порт 4173.
npm test — серверные тесты.
Токен BOT_TOKEN хранится исключительно в свойствах Apps Script. Сервер проверяет Telegram initData для всех личных данных и изменений.
public/transport.js отправляет JSON как text/plain без пользовательских заголовков; ответ проверяется, повтор заказа защищён requestKey.
Фотографии хранятся на Google Drive и читаются через Apps Script.
Служебные SmokeTest.gs и ServerSetup.gs запускаются только вручную из редактора. Не запускайте их повторно без необходимости: они добавляют помеченную тестовую запись.
